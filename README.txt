WORKOUT TRACKER - CLOUD SYNC + PROGRAM MANAGEMENT

This version adds phone-first program management on top of the Supabase cloud sync prototype.

Program management:
- Add/remove exercises
- Reorder exercises
- Activate/deactivate exercises
- Change sets and rep targets
- Set target weights per set (comma-separated)
- Configure progression: add to last set, add to every set, or no automatic increase
- Add routines
- Export/import full backup

Workout screen uses the master program definition and shows per-set target weights as placeholders.

Supabase setup remains the same as CLOUD_SETUP.md.
